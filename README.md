# Projeto E-commerce 🛒

Projeto de interface de loja virtual desenvolvido com **HTML, CSS e JavaScript**.

> **Categoria:** desenvolvimento web / e-commerce demonstrativo · **Repositório original:** [Carla1331/Projeto_E-ccomerce](https://github.com/Carla1331/Projeto_E-ccomerce)

## Objetivo

Praticar a construção e a organização de páginas web relacionadas a uma experiência de comércio eletrônico, separando conteúdo, apresentação e comportamento com tecnologias nativas da web.

## Tecnologias

| Tecnologia | Responsabilidade |
| --- | --- |
| HTML5 | Estrutura das páginas |
| CSS3 | Apresentação e estilos |
| JavaScript | Comportamento da interface |

## Organização do projeto

```text
Projeto_E-ccomerce/
├── .vscode/         # Configuração do editor
├── img/             # Imagens e recursos visuais
├── index.html       # Página inicial
├── products.html    # Página de produtos
├── script.js        # Código JavaScript
└── styles.css       # Estilos
```

## Como executar

O repositório não apresenta arquivo de gerenciamento de dependências na raiz. Para visualizar a interface:

```bash
git clone https://github.com/Carla1331/Projeto_E-ccomerce.git
cd Projeto_E-ccomerce
```

Abra `index.html` no navegador. Durante o desenvolvimento, você pode utilizar um servidor estático local, como o **Live Server** do VS Code.

## Escopo verificado

- Página inicial e página de produtos;
- Organização de arquivos HTML, CSS e JavaScript;
- Imagens armazenadas em diretório próprio.

**Não estão confirmados**: API de produtos, back-end, banco de dados, carrinho persistente, processamento de pedidos e integração de pagamentos. Evite apresentar esses recursos como implementados sem inspecionar o código.

## Oportunidades de evolução

São **sugestões**, não entregas concluídas: adicionar imagens reais da interface, explicar as interações existentes, testar acessibilidade e navegação, rever responsividade e introduzir testes para funções JavaScript relevantes.
